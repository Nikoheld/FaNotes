# FaNotes baseline profile (human-readable ART profile rules).
# AGP compiles this into the release APK (assets/dexopt/baseline.prof) and androidx.profileinstaller
# installs it on first launch, so these paths run AOT-compiled from the start instead of interpreted
# until JIT warms up. Compose, Material 3 and AndroidX ship their own profiles; these rules add the
# app's hot paths: start-up, opening a note, the pen (touch, live stroke, tiles), PDF pages, autosave.
# H = hot, S = start-up, P = post-start-up. See android/PERFORMANCE.md.
